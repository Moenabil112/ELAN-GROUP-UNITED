# ELAN Group United — كوكبت الذكاء المالي لأصحاب المصلحة

**Stakeholder Intelligence Cockpit** — نافذة عربية خاصة (RTL) لأصحاب مصلحة منظومة إيلان للتعدين الذكي، محورها لوحة نموذج مالي بأفق 15 سنة لنافذة التشغيل المحلية.

> جميع الأرقام المعروضة في هذه النافذة توضيحية ومشتقة من نموذج عمل أولي، ولا تمثل ضمانًا أو عرضًا ملزمًا أو دعوة استثمار عامة. أي قرار استثماري يحتاج إلى مراجعة مالية وقانونية وتشغيلية وفنية مستقلة.

## نظرة عامة

الواجهة كوكبت قرارات لا صفحة تسويقية: الشاشة الأولى لوحة مالية تعرض إطار الدخول المعتمد (الخيار B) وثلاثة سيناريوهات نمذجة يبدّل بينها المستخدم فتتحدث المؤشرات والمخططات فوراً.

**الإطار المالي المعتمد (الخيار B فقط):**

- رأس مال الدخول: **100 مليون ريال** — يُنشر مرحلياً عبر بوابات حوكمة.
- الحصة التفاوضية: **30%** من **نافذة التشغيل المحلية** حصراً.
- **517 مليون ريال**: تقييم Post-money مرجعي للمنظومة الأوسع — مرجع حجمي فقط، لا يُستخدم لإعادة احتساب الحصة.
- أفق النموذج: **15 سنة**.

## الصفحات

| المسار | المحتوى |
|---|---|
| `/` | الكوكبت المالي: بطاقات الدخول، محدد السيناريو اللاصق، مخططات الإيراد والتكاليف والتدفقات والتوزيعات، مؤشر الاسترداد، لوحة الحساسية، خريطة استخدام رأس المال، افتراضات النموذج |
| `/ecosystem` | خريطة الطبقات الثماني التفاعلية — كل طبقة موصولة بمؤشر مالي وخطر وصاحب مصلحة |
| `/rooms` | غرف أصحاب المصلحة الست (المستثمر، المالية، الحوكمة، التشغيل، البيانات، الإيكوسيستم) |
| `/governance` | سجل المخاطر الثمانية مع الاستجابات الحوكمية وإيقاع المراجعة |
| `/data-room` | بوابة الوثائق المقفلة («يتطلب صلاحية وصول») + مسار المراجعة الرسمي من ثماني خطوات |

## التقنية

Next.js 15 (App Router) · React 19 · TypeScript (strict) · Recharts · CSS tokens (بدون Tailwind) · عربية RTL كاملة مع خط Inter للأرقام داخل عناصر معزولة الاتجاه.

## التشغيل

```bash
npm install     # تثبيت الاعتماديات
npm run dev     # خادم التطوير — http://localhost:3000
npm run build   # بناء الإنتاج (يشمل فحص الأنواع)
npm run start   # تشغيل بناء الإنتاج
```

## النشر على Vercel

المشروع جاهز دون أي إعداد إضافي: اربط المستودع بـ Vercel وسيكتشف Next.js تلقائياً (أمر البناء `next build`). كل الصفحات مولّدة سكونياً.

## بنية المشروع

```
/src
  /app          الصفحات (App Router) + globals.css (رموز التصميم)
  /components   layout · dashboard · ecosystem · rooms · risk · data-room · shared
  /data         النموذج المالي والسيناريوهات وطبقات المنظومة والغرف والمخاطر والوثائق
  /lib          finance (الحسابات) · formatters · validators (فحوصات الاتساق)
  /types        أنواع TypeScript المالية والهيكلية
/legacy-static  النسخة الثابتة السابقة محفوظة كما هي
```

كل المحتوى والأرقام تُدار من `src/data/` — تعديل الافتراضات هناك ينعكس على كل المخططات والمؤشرات دون لمس الواجهة. دوال الحساب في `src/lib/finance.ts` (إيراد سنوي، تكاليف، تدفقات، توزيعات، سنة استرداد نموذجية، ملخصات سيناريوهات).

## ملاحظة الترحيل

النسخة السابقة كانت نافذة سردية ثابتة (HTML/CSS/JS) — محفوظة كاملة وقابلة للتشغيل في `/legacy-static/index.html`. تفاصيل التدقيق وما رُحّل وما استُبدل في [`MIGRATION_PLAN.md`](./MIGRATION_PLAN.md).

## الانضباط المالي في الكود

- لا لغة عوائد مضمونة أو استرداد مضمون — سنة الاسترداد «نتيجة سيناريو» وقد تكون «خارج أفق النموذج».
- كل الافتراضات موسومة «افتراضات أولية قابلة للمراجعة».
- قنوات الإيراد الخمس تُعرض «قابلة للتحقق عبر العقود والتنفيذ» — لا ادعاء بعقود موقعة.
- `src/lib/validators.ts` يتحقق آلياً من ثوابت الخيار B ومن أن مجموع مراكز الإنفاق يساوي 100 مليون ريال، وتظهر نتيجته شارة في الكوكبت.
- مكوّن إخلاء المسؤولية (`DisclaimerBlock`) إلزامي قرب كل مخرج مالي.
