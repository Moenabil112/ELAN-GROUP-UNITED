# نافذة الدخول السيادي في منظومة إيلان للتعدين الذكي

**ELAN Group United — Sovereign Mining Intelligence Entry Window**

نافذة رقمية عربية خاصة (RTL) موجهة لمستثمر سيادي/استراتيجي محلي يدرس دخولاً برأس مال قدره 100 مليون ريال مقابل حصة تفاوضية 30% في نافذة التشغيل المحلية.

> جميع الأرقام المعروضة توضيحية ومشتقة من نموذج عمل أولي، ولا تمثل عرضًا ملزمًا أو وعدًا بعائد. أي دخول استثماري يحتاج مراجعة مالية وقانونية وتشغيلية مستقلة.

## التشغيل

المشروع ثابت بالكامل ولا يحتاج أي خطوة بناء:

```bash
# الخيار 1: فتح الملف مباشرة
open index.html

# الخيار 2: خادم محلي
python3 -m http.server 8000
# ثم زيارة http://localhost:8000
```

## بنية المشروع

```
├── index.html              # الهيكل الدلالي للنافذة (12 قسمًا)
├── assets/
│   ├── css/
│   │   └── styles.css      # الهوية البصرية — أخضر سيادي، جرافيت، رمل، ذهبي هادئ
│   └── js/
│       ├── data.js         # بيانات المحتوى المهيكلة (المقاييس، التوزيع، القنوات، المخاطر…)
│       ├── components.js   # مكوّنات العرض القابلة لإعادة الاستخدام
│       └── main.js         # ربط البيانات بالمكوّنات + الكشف التدريجي
```

## المكوّنات

| المكوّن | الغرض |
|---|---|
| `HeroFinancialCard` | البطاقات المالية الأربع (100م ريال، 30%، 517م ريال، 10–15 سنة) |
| `LayerCard` | الطبقات الخمس للمنظومة |
| `UseOfFundsCard` + `UseOfFundsWheel` | خريطة توزيع رأس المال (عجلة مالية + شبكة) |
| `RevenueChannelCard` | قنوات الإيراد الخمس |
| `TimelineStep` | رحلة القيمة 0–15 سنة |
| `RiskGovernanceCard` | المخاطر واستجاباتها الحوكمية |
| `DeepDiveAccordion` | وحدات طبقة التعمق المالي |
| `CTASection` | لوحة الخطوة التالية |

## تحديث المحتوى

كل المحتوى والأرقام في `assets/js/data.js`. تعديل أي رقم أو نص هناك ينعكس على الواجهة دون المساس بالهيكل أو التصميم.

## الإطار المالي المعتمد (الخيار B فقط)

- رأس مال الدخول: 100 مليون ريال.
- الحصة التفاوضية: 30% من نافذة التشغيل المحلية حصراً.
- التقييم المرجعي Post-money للمنظومة الأوسع: 517 مليون ريال (مرجع حجمي فقط، لا يُستخدم لإعادة احتساب الحصة).
- الأفق الاستثماري: 10–15 سنة.
