---

### Document Purpose

This register (ضبط الإصدارات) records the version history of every data-room document — version number, date, change summary, change and review owners, approval status, previous-version reference, current approved version, and archived versions. It enforces the rule that **every version is a new record; nothing is overwritten**. **All figures are illustrative and model-derived.**

---

### Executive Summary

Versioning follows a fixed sequence from **v0.1 Initial Draft** to **v1.0 Approved for Review** and beyond, with each step recorded. Every change creates a new version entry with a summary, owner, and approval status; prior versions are archived, never deleted; and the current approved version is always identifiable. The register works with the Review Tracker (Document 04): review outcomes drive version advancement, and it mirrors the ecosystem's deposit convention (new file + manifest entry per version).
