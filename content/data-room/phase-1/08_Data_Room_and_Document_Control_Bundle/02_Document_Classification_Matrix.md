### Document Purpose

This matrix defines how data-room documents are classified (تصنيف المستندات) — the classification levels, the document types that fall under each, the access rules, and the handling requirements. It is the reference that every other control document (upload, access, operating procedure) applies. **All figures are illustrative and model-derived; sovereign-sensitive data is held in-country and never leaves.**

---

### Executive Summary

Documents are classified into five levels, from **Open for Initial Review** to **Legal Review Only**, each with a defined access rule and handling requirement. Classification is assigned at deposit and drives every downstream control: who can view, download, or comment, and how the document is watermarked and logged. Public-summary and operating-narrative documents sit at the open end; financial-model detail, legal instruments, and sensitive evidence sit at the restricted end. Classification is the foundation of the access matrix (Document 06) and the operating procedure (Document 07).

---

### Data Room Reference

Five classification levels · aligned to the ecosystem's five data classes (public → confidential-financial/legal) · access governed by RBAC · sensitive sharing gated at OG-11 · sovereign data never exported.

---

### Purpose of Document Classification

Classification ensures each document is disclosed only to those who should see it, handled according to its sensitivity, and controlled consistently across the data room. It converts "confidential" from a label into an enforced rule.

### Classification Level Table — مستويات التصنيف

| # | Level | العربية | Meaning |
|---|---|---|---|
| 1 | Open for Initial Review | متاح للمراجعة الأولية | Shareable for first-look review. |
| 2 | Controlled Access | وصول مقيد | Role-based, need-to-know. |
| 3 | Confidential | سري | Restricted; sensitive business/financial. |
| 4 | Restricted Review | مراجعة محدودة | Narrow audience; negotiation-sensitive. |
| 5 | Legal Review Only | للمراجعة القانونية فقط | Counsel/legal audience only. |

### Document Type Table — أنواع المستندات

| Document type | Typical level |
|---|---|
| Public summary documents | Open for Initial Review |
| Internal review documents | Controlled Access |
| Confidential documents | Confidential |
| Restricted documents | Restricted Review |
| Legal review documents | Legal Review Only |
| Financial model documents | Confidential |
| Operational documents | Controlled Access |
| Supporting evidence documents | Confidential / Restricted |

### Access Rule Table — قواعد الوصول

| Level | Who can access | Prerequisite |
|---|---|---|
| Open for Initial Review | Broad reviewer set | NDA |
| Controlled Access | Role-tagged users | NDA + access tag |
| Confidential | Investor/lender/finance per RBAC | NDA + access tag |
| Restricted Review | Named reviewers only | NDA + explicit grant |
| Legal Review Only | Legal/counsel | NDA + legal role |

*Sensitive-data sharing is additionally gated at OG-11; sovereign geodata is air-gapped and never exported.*

### Handling Requirement Table — متطلبات المعالجة

| Level | Handling |
|---|---|
| Open for Initial Review | Standard logging. |
| Controlled Access | Access-tagged; logged. |
| Confidential | Watermarked; download-restricted; logged. |
| Restricted Review | View-restricted; no download; logged. |
| Legal Review Only | Counsel-only; view-restricted; logged. |
