### Document Purpose

This is the master index (فهرس المستندات) for the entire ELAN data room (غرفة البيانات والمستندات) — every bundle and document, with its numbering, owner, status, access level, review priority, last-update date, and next required action. It is the single navigation point for a reviewer opening the data room. **All indexed documents are v0.1 initial drafts; all figures are illustrative and model-derived; nothing is binding.**

---

### Executive Summary

The data room comprises **eight bundles and 53 documents** (plus a README per bundle), spanning the investment decision, the financial model, use of funds, revenue channels, governance and risk, ecosystem and operations, legal and regulatory review, and this document-control bundle. Every document carries a data-room ID (DR-B#-##), an owner, a status, an access level, and a review priority. This index is the authoritative map; the other documents in this bundle define how documents are classified, uploaded, reviewed, versioned, accessed, and operated.

### Document Numbering System

Each document has a data-room ID: **DR-B{bundle}-{doc}**. Example: `DR-B1-01` = Bundle 1 (Investment Decision), Document 01. READMEs are `DR-B{n}-00`. The ID is stable across versions; the version is tracked separately in the Version Control Register (Document 05).
