### Document Purpose

This document defines the stakeholder rooms (غرف أصحاب القرار والمصلحة) — the role-based views through which each stakeholder engages the ecosystem. For each room it sets the purpose, intended users, main questions answered, key dashboards, required documents, KPI cards, linked risks and decisions, and review cadence. **Access is role-based (RBAC); all figures are illustrative and model-derived.**

---

### Executive Summary

Six rooms give each stakeholder a governed, need-to-know view: the Investor Room for the Strategic Partner, the Finance Room for capital and the cockpit, the Governance Room for gates and decisions, the Operations Room for delivery, the Data Room for governed records, and the Ecosystem Room for the whole-system view. Rooms are **RBAC-governed** (founder, board, investor, lender, legal) and every access is logged. Each room answers a defined set of questions and surfaces defined dashboards and KPI cards, so stakeholders see what they need — no more, no less.

---

### Operating Reference

RBAC roles: founder · board · investor · lender · legal. Financial cockpit (لوحة القرار المالي) reads governed data. Data room governed by classification + access tags. Review cadence per Reporting Cadence Memo.
