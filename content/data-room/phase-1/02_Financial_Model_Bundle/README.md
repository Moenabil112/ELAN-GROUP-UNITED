### Purpose of the Package

This bundle supports **financial review, investment committee analysis, and a detailed understanding of the 15-year dashboard numbers**. It documents the model's outputs, assumptions, scenarios, distribution logic, payback methodology, sensitivities, and capital deployment — so a reviewer can test the model, not just read it. It is prepared for readability by financial reviewers and for conversion into Word or PDF. **All figures are illustrative and model-derived, are working assumptions pending real data, and are not an offer or a promise of return.**

**Held consistently across the package:** the 30% participation attaches to the **Local Operating Entry Window only**; the **SAR 517m** reference anchors ecosystem scale and is **not** used to recalculate the participation; **operating break-even (Year 1)** is distinct from **investor capital payback**.

---

### Relationship to the 15-Year Dashboard

Every figure in this bundle traces to the live model **ELAN-FIN-MODEL-v0.2** (16 sheets). Base-case dashboard anchors (illustrative, SAR m): total channel NPV **736**, model ecosystem value **901**, founder-attributed value **669** (47% cap-table basis), 15-year cumulative revenue **4,090**, plateau revenue **238**, operating break-even **Year 1**. The **SAR 517m** investor reference is deliberately conservative relative to the model's computed ecosystem value; reconciling the two is a financial-review item. Founder-attributed value is a **cap-table output**, not the 30% window partner's return.
